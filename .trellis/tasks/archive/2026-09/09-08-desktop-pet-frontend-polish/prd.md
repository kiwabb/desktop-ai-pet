## Requirements

- **R1 / 角色与兼容性**：保留白猫原图与角色比例、猫爪压角位置/大小/阴影、连续单底盘及5/7脚印。保留独立外观、显式旧tail和dock配置；不靠随意扩大原生窗口修补布局。
- **R2 / 视觉统一**：覆盖收起、紧凑、展开聊天、设置、待办、提醒；统一暖白表面、暖深棕文本、暖橘主操作及字体/间距/边框/阴影/焦点体系。状态色表达真实语义。
- **R3 / 输入与阅读**：中文选词不误发，Enter/Shift+Enter行为清楚；流式阅读不强制打断上翻历史；草稿仅在对应请求被接受后清理，失败不丢输入。
- **R4 / 导航与原生体验**：明确切页返回规则，统一返回图标；完整验证点击、拖动、右键、展开/收起、resize、焦点、隐藏inert与重复操作；动效克制且支持减少动态效果。
- **R5 / 消息与状态**：完善长内容、工具结果、空/加载/错误状态排版；真实连接、模型配置、设备登记分开呈现。不得用静态装饰、假回复或模拟工具充当运行证据。
- **R6 / 设置与任务**：保持本机私有凭证存储、换地址清凭证、状态刷新不覆盖草稿、保存错误/成功契约；统一设置/待办/提醒密度，长内容和提醒同时出现时操作可达。
- **R7 / 适配与交付**：覆盖浅/深/复杂背景、窄内容、屏幕边缘及可用显示环境；完成风险相称的检查、最终原生包验收和回退记录。所有结果区分静态、浏览器、原生、真实服务。

## Acceptance Criteria

- [ ] **AC1 / R1**：原图校验值不变，原猫爪几何/阴影保持，无重影/双底盘；聊天5枚、设置/待办无footer时7枚脚印完整可见；旧tail/dock/独立分支无回归。
- [ ] **AC2 / R2**：六视图同尺度全景对照由用户确认；使用统一视觉规范，正常/空/加载/错误/禁用状态无错位和装饰遮挡。
- [ ] **AC3 / R3**：真实输入法候选确认不发送，组合结束后Enter发送、Shift+Enter换行；上翻阅读不被拉回，恢复跟随规则可观察。
- [ ] **AC4 / R3、R5**：真实请求未接受/失败保留草稿，接受后展开并清除对应草稿；真实流式、工具与完成结果可见，无重复提交/丢消息。
- [ ] **AC5 / R4**：最终包至少连续10轮打开→输入→切页→返回→关闭/重开通过；拖动不误触点击，无闪白、明显漂移、错误焦点或隐藏拦截。
- [ ] **AC6 / R2、R4、R7**：键盘顺序和焦点可见；常规文字对比度≥4.5:1；减少动态效果时非必要动效停用；长文本、较窄窗口和不同背景下操作可达。
- [ ] **AC7 / R6**：设置同endpoint空凭证复用、改地址清凭证、无关快照不覆盖输入、保存失败留表单/成功按契约返回逐项验证；不新增浏览器凭证持久化或日志泄漏。
- [ ] **AC8 / R5、R6**：真实连接/断线/模型未配置/设备离线分开表达；待办和提醒使用真实记录或真实空态，授权写入有回读证据；无伪造结果。
- [ ] **AC9 / R7**：专项检查及必要构建通过；最终包加载最新资源，有截图/录像、证据矩阵与回退点；未执行项明确保留，不能标记整体完成。

## Approved Product Decisions

以下取舍已随用户“开始执行”授权实施：

1. 二级页面返回进入前的聊天形态；保存成功保持既有契约。
2. 从主要输入区隐藏暂未开放的附件/语音占位，不实现这些功能或新增替代容器。
3. 增加安全的常见Markdown/代码块展示和复制，不执行HTML或脚本。
4. 阅读历史时出现明确的回到最新入口，恢复跟随由用户操作/位置决定。
5. 固定在线装饰改为不误导的真实状态表达：先局部设计对照，保持猫本体像素和原图文件不变。

## Out of Scope

- 更换角色、换装、小游戏、主题商店、语音/附件功能、模型选择器、新提醒渠道。
- 重构智能体后端或业务协议，制造消息/待办/凭证/模拟连接来填充验收。
- 未明确列明的真实配置、待办或提醒写入；远端发布；顺手归档其他任务。
- 无依据的大范围重构和依赖升级；原生问题只有在复现后才按最小边界处理。

## Risks and Deferred Verification

原生自动化限制、多显示器环境和真实服务可用性必须分别记录。实际业务写入先列明对象、操作与影响。旧任务局部浏览器通过是基线，不能替代本任务最终原生/真实服务验证。消息渲染采用 react-markdown 10.1.0 + remark-gfm 4.0.1；默认禁用原始 HTML，远程图片不自动加载，链接采用显式协议白名单。
