# 定制桌宠技术设计（已确认）

## 修改边界

行为缺口在固定宠物渲染、固定主题、缺少素材生成/保存三个模块；不能通过只替换静态 URL 解决。新增 Rust customization 模块、React 定制页面、图片服务设置与跨窗 appearance hook，有限修改 App/PetStage/PetExpression、主题变量和 Tauri 命令注册。聊天运行时、SQL业务表及旧白猫素材不修改。

## 资产与执行

应用配置目录下 customization/v1/{presets,jobs}，manifest 包含版本、id、名字、状态图片的相对路径/尺寸/透明范围/落脚锚点、主题值、来源阶段及创建时间；active.json 保存活动ID及revision。路径仅为应用生成的ID，禁止外部路径或目录跳转。内置默认方案只读，不复制白猫遮罩到自定义素材。

任务阶段：validating → generating-base → generating-closed → generating-happy → generating-talk → validating-assets → deriving-theme → ready；终态 failed/cancelled/interrupted。Rust单独任务槽，不占聊天worker。每次请求带job revision，取消/新任务使旧结果失效。重启不重发收费请求；保留已完成文件和可显式重试的阶段。

多参考图先生成单一角色主形象，再以主形象为首参考制作派生状态；相同画布和主尺度。自动解码、alpha检查、内容边界及比例/位置规范化，不通过简单强制白底删除破坏毛发。有效alpha仍不证明身份一致，最终预览需看四个状态；偏差过大的产物提示重做。

## 模型服务

专用 images/edits multipart 适配器，地址/模型可配置，支持透明PNG与base64输出的明确契约。HTTPS及回环HTTP规则沿用现有URL校验，禁跨主机携带密钥的重定向。密钥独立系统存储命名空间，不自动拿聊天密钥传给其他服务。阶段请求数量可见，取消中断本地等待但不保证退款，不对超时/未知响应自动重试。

## 主题与界面

从生成主形象的不透明主体像素提取主色，确定性生成柔和表面、强调、文字、边线、hover/focus/shadow色；检测文字与按钮对比，不采用背景大块颜色支配主题。用户可调主色；错误/成功语义仍清晰。原奶油杏色为default preset。

在现有面板增加定制页面，不建立常驻第二头像或装饰底盘。上传与生成页展示实际参考/阶段；预览页提供四状态切换与真实组件示意（不伪造聊天记录）。预览只改页面局部样式；用户应用后才更新桌宠和面板全局主题。

## 同步、保存与恢复

生成资产暂存，验证全部通过后才写完整preset；active pointer原子替换，广播带revision事件。窗口先订阅再读快照，拒绝旧revision；重开读取权威选择。应用前预解码资产，失败维持旧preset；已落盘但广播失败与保存失败分开报告。恢复默认只切active，不删用户方案。删除仅允许非活动、非任务引用方案，并确认目标后删除对应目录。

## 安全与资源预算

图片文件签名/解码/尺寸/数量双层检查；传输大小、响应大小、总任务时长均有限额。原始上传文件只读，规范化副本归应用管理。资产加载用限定目录或验证后字节交付，不开放任意文件读取。日志只记录阶段、耗时和错误类别。图片生成任务不包含聊天历史。

## 风险与验证

参考身份一致性由真实预览验证；透明背景由alpha检查+原生桌面对照验证；跨窗延迟与持久化异常用针对性测试及实际重启验证。真实服务未配置时可以交付可审查代码，但不能标记完整功能验收成功。

## 2026-10-03 AI 导入主题变更边界（覆盖旧派生主题阶段）

缺口由导入生命周期和主题执行模型共同造成：上传仅做缩略图，生成完成后才本地取色。现在导入应自动调用视觉模型，保存准确图片与主题绑定。

Rust customization 新增独立视觉请求适配器及单一草稿任务。沿用当前单机聊天 endpoint/model 和 Rust 凭据读取，不附带对话历史，不改聊天执行器。前端负责有序提交与选择 epoch，Rust 负责 draft/attempt fencing、规范化副本、校验与原子存储。生成 start 消费 ready draft，冻结参考图和主题到 Job；后续 retry 不改主题，完成原样写 Preset。旧无主题任务沿用兼容恢复。

Theme 保留旧四字段，新增可选 design 与 source。design 版本1包含 name/summary，八个语义颜色，matte/paper/glaze 材质，12–24圆角、1–2边框、0–3阴影、soft/solid/outlined控件。所有字段严格校验；source 由实际调用模型与时间生成。前端只映射白名单 CSS tokens 并修正对比度；SVG 外形与面板材质保持同源。

边界：Rust customization/*及必要命令注册；frontend customization模型/UI/主题渲染与组件样式；必要测试与规范。既有聊天、业务数据库、账号、默认角色及上传原文件不修改。固定主题图库退出主流程。预览不激活，不做假业务演示。
