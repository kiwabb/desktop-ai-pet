# 桌面 AI 白猫

这是一个基于 Tauri 2 的悬浮桌面 AI 助手。桌宠使用三张透明 PNG 实现呼吸、眨眼、说话和睡眠动画，不依赖收费动画或 3D 运行时。

## 快速启动

```bash
pnpm install
pnpm pet2d:validate
pnpm tauri dev
```

先按 [服务端说明](server/README.md) 启动独立 Python 助手服务并签发设备凭证。点击白猫打开聊天窗口，在设置中填写助手服务地址和设备凭证。本机开发默认服务地址为 `http://127.0.0.1:18081`；跨设备部署使用 HTTPS。客户端不需要安装 Python。

## 当前能力

- Tauri 2 双透明窗口：桌宠常驻，聊天按需显示
- macOS 跨桌面空间显示，并覆盖普通全屏应用
- 原始、闭眼和张嘴三张对齐帧
- 呼吸、随机眨眼、说话嘴型、睡眠、好奇、开心和拖拽反馈
- 点击展开或收起聊天面板
- Rust 原生层连接服务端控制通道与设备通道
- Python LangGraph 智能体调用模型及待办创建、查询、完成和提醒工具
- 聊天框中的待办列表直接读取服务端，展示标题、状态与创建时间，支持刷新，无需调用模型
- PostgreSQL 持久保存会话、任务、工具结果和待办；重连恢复快照
- Redis 保存设备在线租约；当前设备操作能力为空
- 设备凭证保存在权限为 `0600` 的原生配置文件中，模型密钥只在服务端配置
- 未配置真实模型时禁用发送，不生成假回复

服务端配置使用 `PET_AGENT_` 前缀，见 [配置与启动](server/README.md)。偏好记忆、习惯学习和主动提醒尚未实现；架构方向见 [服务端智能体架构](docs/SERVER_AGENT_ARCHITECTURE.md)。

## 查看和完成待办

点击聊天框右上角的“待办列表”图标直接查看已有事项，再点击“返回对话”继续聊天。点击待完成事项左侧的完成框即可直接保存，不调用模型；保存中显示进度，成功后显示勾选和标题删除线。再次点击勾选框可取消完成，保存成功后恢复为待完成。

完成事项时在聊天中明确指定标题，例如“把整理架构文档这条待办标记为已完成”。仅输入“完成待办”会先询问具体事项；取消完成请直接点击列表中的勾选框；聊天暂未提供取消完成工具，删除尚未提供。

## 资源

运行资源位于 `public/pets/white-cat-v2/`：

- `idle.png`：默认状态
- `blink.png`：眨眼和睡眠状态
- `talk.png`：说话状态

可编辑的原始 PNG 保存在 `../pet-2d-assets/white-cat-v2/`。三帧共用 `1207×1303` 的透明画布。运行时不读取该目录。

## 验证

```bash
pnpm pet2d:validate
pnpm build
cargo check --manifest-path src-tauri/Cargo.toml
```

`pnpm pet2d:validate` 会检查三张图片的尺寸、2D 渲染入口和禁止出现的旧渲染依赖。

## 待办提醒

在待完成事项旁点击提醒图标，选择本机日期时间并保存；可修改或清除。桌宠运行且服务可达时，每15秒检查一次到期事项，展开现有面板显示提醒，可选择“完成”或“稍后10分钟”。完成会清除提醒，取消完成不会恢复旧时间。

退出应用或断网期间不即时弹出；重新运行或恢复连接后补显未处理的到期事项。多个设备使用同一账号时各自显示，共享事项状态和提醒时间。列表可直接设置提醒，也可在聊天中提出提醒请求；聊天通过注册工具真实保存。

对话支持创建带提醒的事项，以及为已有待办设置、修改或取消提醒。默认按 Asia/Shanghai 时区理解日期与时间，可通过服务端 `PET_AGENT_DEFAULT_TIMEZONE` 配置；时间已过或不明确时会先询问。助手回复成功以工具返回的提醒时间为准。
