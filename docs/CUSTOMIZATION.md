# 桌宠定制

定制功能已实现基础流程，正在进行真实图片服务和完整原生验收。当前 GitHub 单机基线不包含这项开发中的功能；以下说明对应本地开发版本。

## 创建自己的伙伴

1. 打开聊天面板的 **定制** 页，选择 **新伙伴**，填写名字。
2. 上传同一个角色的 1–4 张清晰照片或插画。支持 PNG、JPEG、WebP；单张最多 10 MiB，合计 30 MiB，解码后不超过 2400 万像素。
3. 首次使用展开 **配置服务**，填写图片服务地址、图片模型和独立 API Key。密钥在应用中填写，保存到系统凭据存储。若与单机聊天使用同一服务，先填写图片模型，再点击 **使用聊天连接**，由应用内部复制已保存的地址和密钥；不会自动复用，也不会改变聊天配置。
4. 查看实际服务目标和请求数量后，点击 **生成我的桌宠**。应用依次生成普通、闭眼、开心、说话形象。
5. 在预览中查看四种状态和配套颜色。满意后保存并应用；只在预览中调整颜色不会立即替换桌面的主题。

初次生成完整方案会发起四个图片请求。图片生成使用你配置的服务并由该服务计费；本应用不内置免费图片模型。

## 导入时生成专属主题

先在助手设置中连接支持看图的聊天模型，再打开 **定制 → 新伙伴**。添加参考图后，应用会自动把这组图片发给页面标明的模型，设计角色专属的完整主题：配色、面板质感、圆角和按钮风格。图片缩略图下方显示真实分析状态、请求次数和主题预览。

每次添加或移除图片都会重新分析当前这一组，通常发起一次模型请求；生成四种宠物状态仍另需四次图片请求。更换图片后，旧分析结果不能替换新图片的主题。分析失败会保留当前桌宠，点击 **重新设计主题** 才重试，不会自动重复收费调用。

主题完成后，查看名称、设计说明和界面样式示意，再点击 **生成我的桌宠**。宠物任务使用这一组已经分析的参考图，完成后保存同一份主题。预览不会改变桌面，也不会写入聊天记录。满意后应用到桌面，聊天、待办、备忘、设置与操作条一起更新。

旧宠物继续使用原来保存的主题。新增流程由导入的图片动态设计，不再提供固定主题画廊或要求你手动调色。生成猫爪保留原图，原猫爪跟随主题。

## 生成配套猫爪

选择已生成的宠物方案，在预览页使用 **生成配套猫爪**。应用把该方案的主形象发送给已配置的图片服务，生成一个匹配角色的透明猫爪标志，无需另外准备标志文件。每次点击额外发起一次图片请求，和四种宠物状态分别计数；不会自动重试。

生成完成后先看候选预览，满意后保存或应用。保存正在使用的方案会同步更新各面板标题；仅生成不会替换当前猫爪。可以恢复原猫爪，再显式保存；之后仍可选用已生成的猫爪，不必为了切换再发起收费请求。取消、生成失败或重启中断会保留已应用的标志。

## 图片服务要求

需要提供兼容的 `/images/edits` 接口，接受多张参考图片，返回真正透明的 PNG 和 `b64_json` 图片内容。仅支持聊天的接口、只返回远程图片链接的接口或不支持透明输出的模型不能满足本功能。

远程地址必须使用 HTTPS，本机回环地址支持 HTTP。服务的图片模型名称应按提供方实际支持值填写。保存配置不代表已验证生成能力；收到并检验真实生成图片后才能确认兼容。

## 失败、取消和重试

- 网络、权限、格式或透明背景校验失败，会保留现有桌宠及已完成阶段。
- 失败后由你主动选择继续，不会自动重复收费请求。仅保存失败时可以重试保存，无需重新生成图片。
- 取消会停止本地等待并丢弃迟到结果，但不能保证图片服务停止计费。
- 重启不会自动继续生成；未完成任务标记为中断，需主动继续。
- 重做已完成方案会创建新结果，保留原来可用的方案。

模型无法保证每次都保持角色一致。若表情、比例或细节不符合预期，请在预览中重做对应状态；不要将有棋盘格底的图片视作透明素材。

## 保存和恢复

生成素材与方案保存在应用管理的本地定制目录中，与聊天数据库、待办、备忘和聊天连接配置分开。已保存方案不依赖原始参考文件的位置。支持切换、改名、保存图片生成的主题及恢复默认白猫；删除前应先切换到其他方案。

默认白猫及其原始素材保持不变。损坏或缺失的活动素材会给出告警并恢复可用的默认形象。

## 当前验证边界

单元测试、前端构建与原生入口检查已经进行。本地已有真实四状态生成和应用记录。配套猫爪已通过一次真实图片请求完成生成，并在原生应用验证候选预览、保存、恢复原猫爪、无额外请求复用以及重启保留。聊天紧凑/展开、待办、备忘与设置标题均已检查；原宠物素材保持不变。完整定制功能的其他异常和恢复场景仍以逐项原生验收记录为准。

完整主题已验证真实三花/小虎的本地取色、六套选项、预览隔离、浓度调节、保存应用、桌宠操作条和面板同步，以及重启保留。原图片和图片请求计数未变。本轮原生应用的助手数据仍处于加载状态，因此只确认这些页面的主题呈现，不将其记作有业务数据的聊天/待办/备忘流程验收。
